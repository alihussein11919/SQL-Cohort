**Cohort analysis / Customer Retention Rate using MS SQL server and Tableau**

Downloaded Raw data as CSV  which contained nearly 500,000 records,
and then Imported Into MS SQL server using flat file import wizard, from there, multiple steps were done to Clean the data to prepare it and make it ready for analysis to Extract the desired insights, including removing duplicates and nulls.
Afterwards, the tables were saved and exported to tableau in order to preform all the required visualization. 
Cleaned ~540K raw retail transactions in SQL Server, removing null customers, invalid quantities and prices, and 5,215 duplicates, leaving 392,669 unique rows.
Built monthly cohort and retention tables and a Tableau heatmap dashboard: the Dec 2010 cohort (883 customers)
